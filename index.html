Extras

RTP (Run Time Package)

Some games rely on the graphics and sounds of the RPG Maker RTP instead of shipping them. If a game shows missing graphics or the player reports missing files, import your RTP once and every game will use it. Use the RTP folder of your RPG Maker / RTP installation, as a folder or ZIP.

  • RPG Maker 2000 RTPnot installed
  • RPG Maker 2003 RTPnot installed

MIDI music (SoundFont)

Most RPG Maker games play MIDI music. Without a SoundFont the player uses a basic built-in synthesizer. Add a General MIDI SoundFont (.sf2), such as the free GeneralUser GS, for much better sound in every game.

Help

Which games work?

Games made with RPG Maker 2000 and RPG Maker 2003 (also called RM2k / RM2k3), including most games that use common patches such as Power Mode, DynRPG (partially), Maniac Patch (partially) and EasyRPG features. RPG Maker XP, VX, VX Ace, MV and MZ games are not supported. See the EasyRPG compatibility notes for details.

How do I add a game?

Drop the game's ZIP file onto the box at the top, or click Choose ZIP file…. If you already extracted the game, click Choose folder… and pick the game folder (it contains RPG_RT.ldb and RPG_RT.lmt). Archives in other formats (RAR, 7z, LZH) need to be extracted first. ZIP files with Japanese file names are handled automatically.

Controls

Arrow keys or WASD move, Enter/Space/Z confirm, Esc/X cancel and open the menu, Shift is used by some games. F1 opens the player settings (volume, key mapping, scaling), hold F to fast-forward, F12 returns to the title screen. On phones and tablets an on-screen gamepad appears; gamepads are supported too.

Where are my save games?

When you save in a game, the save file is stored in this browser and is still there next time — even after you reload or update the game. Use the ⋯ button of a game in your library to export saves as a ZIP (to back them up or move them to another device) or to import SaveXX.lsd files, including saves from the PC version of the game.

Graphics or sounds are missing

The game probably needs the RPG Maker RTP. Import it under Extras; games made for the Japanese RTP also work with the English RTP and vice versa. Some games also need their own extra files — make sure you imported the complete game folder.

Text looks garbled

The player detects the text encoding automatically. If it guesses wrong, open the game's ⋯ menu in your library and choose the right encoding (for example Japanese for games made in Japan).

Hosting games on this website

Website owners can publish games for everyone: copy a game folder to games/<name>/, run node tools/gencache.mjs and commit the result. The game then appears under Games on this site. See the README for details. Only publish games you are allowed to distribute.

Privacy

This website has no server-side code, accounts, cookies or analytics. Imported games, saves and settings never leave your browser.
